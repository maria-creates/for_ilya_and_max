# Касания Q4 — Аутбаунд Pragmatica

Отчёт за IV квартал 2026: квартальные итоги, календарные месяцы и интерактивная разбивка по неделям и ньюбизам.

Сайт: https://maria-creates.github.io/for_ilya_and_max/

## Обновление

GitHub Actions запускает `node scripts/build_report_site.js`. Если настроены секреты `AMOCRM_TOKEN` и `AMOCRM_SUBDOMAIN` (или `AMOCRM_API_BASE`), он получает новую выгрузку и пересобирает этот формат. Без секретов публикует сохранённый снимок.

Локальная сборка из приватной JSON-выгрузки:

```
node scripts/build_q4_dashboard.js /путь/к/выгрузке.json
```

Шаблон: `reports/q4-touches-dashboard/template.html`. Публикуемые файлы: `site/`. Данные включают только агрегированные значения: имена контактов, тексты заметок и токены в сайт не попадают. Библиотека D3 7.9.0 включена локально, обращения к CDN при открытии страницы не требуются.

Недели — понедельник–воскресенье с обрезкой по периоду, месяцы — календарные. Продолжающиеся контакты считаются отдельно за каждый период, поэтому суммы недель и месяцев не равны квартальному итогу. Расчёт ограничен 31 декабря 2026 года.
